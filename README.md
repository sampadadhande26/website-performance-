# Website Performance Analysis 📊

## 📌 Project Overview
This project analyzes website performance using Python and data analytics techniques. It explores website traffic, user activity, session trends, engagement rates, and traffic sources to understand how users interact with a website.

## 🎯 Objectives
- Analyze website users and sessions over time.
- Identify which traffic channels attract the most users.
- Compare average engagement time across channels.
- Understand the distribution of website engagement rates.
- Compare engaged and non-engaged sessions.
- Analyze website traffic by hour and channel.

## 🛠️ Technologies Used
- **Python**
- **Pandas** – Data cleaning and manipulation
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Data analysis environment

## 📂 Dataset
The project uses exported website analytics data containing metrics such as:
- Channel Group
- Date and Hour
- Users
- Sessions
- Engaged Sessions
- Average Engagement Time per Session
- Engagement Rate
- Event Count

## 📈 Key Analysis
- Website traffic trends over time
- Total users by traffic channel
- Average engagement time by channel
- Engagement rate distribution by channel
- Engaged vs. non-engaged sessions
- Hourly traffic patterns across channels

## 💡 Key Learnings
- Practiced data cleaning and preprocessing using Pandas.
- Worked with date-time conversion and numerical data types.
- Created visualizations to explore website performance.
- Developed practical skills in exploratory data analysis (EDA).
- Learned how to interpret user engagement and traffic patterns.

## 🚀 Conclusion
This project demonstrates the use of Python for website performance analysis and data visualization. It provides a foundation for understanding website traffic and user engagement through data-driven insights.

**Project Type:** Data Analytics | Exploratory Data Analysis | Data Visualization
